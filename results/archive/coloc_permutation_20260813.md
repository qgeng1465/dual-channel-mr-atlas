# E1：coloc PP.H4 阈值负对照 / permutation 标定（2026-08-13）

> 目的：回答 eBioMedicine 闸门 E1——"PP.H4≥0.8 的 strong coloc 调用在零假设下
> （同一区域独立 eQTL 与 GWAS 信号、无共享因果变异、LD 结构保留）出现多少次？"
> → 经验假阳性率 + 期望 FP 计数，给"一致性率 13%"一个可辩护的假阳性读数。
> 方法：`scripts/M14_coloc_permutation.R`，经资源仲裁（4 核）后台运行 ~9 分钟。
> 产出：`results/grid/coloc_permutation_calib.csv`（106 行）+ 本报告。
> 纪律：探索性敏感性，独立输出，不触碰预注册主流程；B=100。

## 1. 方法与数据构建（与 M5 完全同源）

- **对象**：106 个 strong coloc 对（PP.H4≥0.8）。
- **数据**：`_coloc_gwas/{GCST}_{ENSG}.rds`（GWAS 区域，与 M5 同一缓存）+
  eQTLGen 全量 cis-eQTL（beta=Z/sqrt(N), se=1/sqrt(N)）+ SNP_AF（eAF 按 AssessedAllele）。
- **对齐**：M5 `harmonize` 原逻辑（等位翻转 + palindromic 用 eAF 解析，MAF 0.01–0.99），
  逐对重建 coloc.abf(p12=1e-5) 输入。
- **置换**：把 eQTL beta 向量跨 SNP 打乱（`sample`），保持 GWAS 信号与每 SNP 的
  varbeta/MAF/N 不变 → 打破 eQTL–GWAS 共享因果对齐，保留两套信号的边缘分布与 LD 结构。
  每个 strong 对跑 B=100 次，统计 permutation 下 PP.H4≥0.5/0.8/0.9 的经验频率。

## 2. 关键有效性校验：重建精确复现原 coloc

观测 coloc（未打乱）与 `transcript_coloc_hits.csv` 的 PP.H4 逐对对比：
**106/106 对偏差 = 0.0000（最大偏差 0.0，中位 0.0）**。→ 置换脚本的数据构建与 M5 逐位一致，
标定针对的就是产生 106 个命中的同一 coloc 流程，非"另一个近似流程"。

## 3. 结果：零假设经验 FP 率（106 对 × 100 置换 = 10,600 次 coloc）

| 阈值 | 零假设经验 FP 率 | 106 个调用中期望 FP |
|---|---|---|
| PP.H4 ≥ 0.5 | 3.92% | 4.16 |
| **PP.H4 ≥ 0.8（strong 阈值）** | **1.45%** | **1.54** |
| PP.H4 ≥ 0.9 | 0.60% | 0.64 |

- **观测 106 个 strong 调用 vs 零假设期望 1.54 → 富集约 69 倍。**
- 在"同一区域独立 eQTL + GWAS 信号、仅 LD 巧合"的零假设下，coloc 的 PP.H4≥0.8 阈值
  特异性极高（假阳率 ~1.5%）；106 个 strong 调用绝大多数是真实共享信号，而非 LD 伪影。
- 与 HEIDI 对照：观测 strong 集 HEIDI 通过 76/106=71.7%，远高于零假设期望（~1.5% 假阳）。

## 5. 诚实解读（怎么写进论文）

1. **coloc 阈值标定到位**：在保留 LD 结构与边缘信号的零假设下，PP.H4≥0.8 经验假阳率
   1.45%（期望 FP 1.54/106）→ "106 个 strong 调用"可辩护为真实共定位信号占主导，
   非 LD 巧合；"一致性率 12.9%（106/819，规范口径 = `transcript_coloc.csv` MR 显著测试数；
   HEIDI 上下文 818=819−1 非可运行测试）"可升级为"MR 显著集约 1/8 获共定位支持，
   该 ~1/8 在置换标定下假阳率 ~1.5%"。
2. **标定的边界（不能过度声称）**：置换零假设只破坏"共享因果"这一对齐，**不建模**：
   真实多效性、样本重叠偏置、或"同一变异同时影响 eQTL 与结局但非因果"的混杂结构；
   这些仍需 HEIDI/Steiger/孟德尔随机假设覆盖。置换标定回答的是"**仅靠 LD 巧合能不能
   造出 strong coloc**"，答案是几乎不能（1.5%）。
3. **脆弱对单独列出**：ZNF34×t2d 的 coloc 调用在置换下不可靠，须在补充表标出，
   从优先位点表降级。
