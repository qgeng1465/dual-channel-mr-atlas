**② M18 参考面板零杂合（亲测定性，比核查 agent 更准）**
- 核查 agent 报告「全面板零杂合、40% 缺失」并推断面板损坏 → 我最初据此撤回 92 簇。
- **亲测复核**：① 两个独立解码器（numpy + 纯 Python 逐字节）交叉验证零杂合坐实（非解码 bug）；
  ② 但**对照验证表明 r² 仍反映真实 LD 结构**——K-ATP block rs5215×rs757110 = 0.918（plink R-sq）
  vs 真实 0.94–0.99；远距离背景 r² median=0.0023、p90=0.015、>0.05 仅 0.5%（chr16 9559 对）；
  ③ 缺失为**个体水平**（Jaccard 0.88–1.0），MAF 合理 → 面板疑为 **haploid 化/简化 + 个体排除**，
  而非随机损坏。
- **修正结论**：92 簇**保留但为保守上限**（r² 轻微低估，真实可能 ~90–91）；stage2 本地 clump
  （r²<0.01@1000kb）受影响很小（背景噪声 0.002 < 阈值 0.01，实测吸收率 median 0.011 正常）；
  位置聚类（bim 坐标，不依赖基因型内容）独立佐证 89–88 独立位点。已更新
  `ld_clustering_20260813.md` 终版与 PUBLICATION_STORY。
- **教训**：核查 agent 的红旗是**正确的触发**（数据确非标准），但其「完全无效」推断**过强**——
  需以对照实验（已知真实 LD 对）为准绳定性，而非仅凭「零杂合不可能」先验。
