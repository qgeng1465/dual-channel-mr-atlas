# P6：eQTLGen–GWAS 样本重叠敏感性（诚实说明，2026-08-13）

> 状态：定性+方向性讨论（must-do 最低档："至少讨论/粗估"）。量化需要两样本重叠矩阵
> （cohort-level），当前本地无 eQTLGen cohort 到各 GWAS cohort 的映射明细，故不做伪精确量化。

## 1. 问题是什么

- 暴露侧：eQTLGen 全血 eQTL（n=31,684，欧洲多队列 meta，含 Rotterdam/LifeLines/FHS/InCHIANTI 等）。
- 结局侧：T2D=Mahajan 2022（ebi-a-GCST006867）、CAD=UKB+meta（005194）、FBG（005186）。
- 两套数据部分共享样本（eQTLGen 多个队列也进入 T2D/CAD 的 GWAS meta）。
- **已知后果（Zhu et al. SMR 2016；Pickrell 2014）**：当 eQTL 与 GWAS 样本重叠时，
  SMR/MR 单工具估计在**零因果假设下**产生正相关偏倚（假阳方向）；重叠越大、遗传相关越高，偏倚越大。

## 2. 对本研究头号读数的方向影响（关键诚实点）

| 读数 | 样本重叠的影响 | 方向 |
|---|---|---|
| **一致性率 106/819 = 12.9%**（Wilson 95% CI 10.8–15.4%，规范口径；HEIDI 上下文 818=819−1） | MR 阶段重叠 → 更多**假阳性 MR 显著**进分母 → 一致率**被低估（保守）** | 保守偏误 |
| **coloc strong 76/106 HEIDI 通过 = 71.7%** | coloc 与 HEIDI 同区域，重叠对两者的偏倚部分抵消；HEIDI 靠 LD 同质性判定，对重叠相对稳健 | 大致中性 |
| **E1 置换标定（1.45% FP）** | 置换保留真实 GWAS 信号、打乱 eQTL；样本重叠体现在**真实** eQTL 上，不进入置换零假设 | 中性（标定的是"独立信号仅 LD 巧合"） |

- **结论**：样本重叠若存在偏倚，是**让"13% 一致率"更保守**（MR 假阳被垫进分母），
  不改变"多数 MR 显著未获区域共定位支持"的方向性结论。
- 需在论文明确："由于 eQTLGen 与结局 GWAS 部分样本重叠，MR 阶段假阳性率可能被低估，
  但一致性率的保守方向使主结论（coloc 支持子集小）稳健；E1 置换标定不依赖重叠假设。"

## 3. 我们做了什么缓解（如实）

1. **E1 置换标定**：置换破坏 eQTL–GWAS 对齐，重叠偏倚进入观测值而不进入零假设；
   106 strong 调用 vs 零假设期望 1.54 → 富集 69 倍，不依赖重叠假设。
2. **HEIDI 同质性**：区域 LD 同质性判定对样本重叠相对稳健（检验的是"单因果变异 vs 多信号"，
   非效应量大小）。
3. **方向敏感性**：Steiger 方向（96.1% eQTL→outcome）与样本重叠无关。
4. **蛋白通道双平台核查（M13）**：PCSK9×CAD 在 deCODE（冰岛，与 UKB 无重叠）× UKB-PPP
   双平台同变异同向双 GWS → 跨平台复现不受单平台重叠影响。

## 4. 明确的局限（写进 Limitations）

- 未做定量重叠校正（SMR 需要 eQTLGen–GWAS cohort 重叠矩阵；Bhattacharjee 2012 的
  LDSC 重叠校正需要 GWAS 面板相关，超出本地数据）。
- 若审稿人要求定量：提供 eQTLGen 队列清单 + 各结局 GWAS 队列清单，按已知共享队列
  （如 Rotterdam、LifeLines、NFBC、FHS）粗估重叠度；或改用**无重叠敏感性**
  （如 INTERVAL 全血 eQTL n=3,901 与 UKB GWAS 无重叠）做核对。

## 5. 结论

样本重叠是一个真实的、方向已知的局限：**偏向保守**。不推翻任何头条数字；
论文在 Methods/Limitations 明确声明，并提供置换标定与跨平台核查作为不依赖重叠的独立证据。
