## 0. 一页结论

项目现状（诚实）：**图谱型阳性成立、新发现型阳性缺位**。106 strong coloc + HEIDI 71.7% + Steiger 96.1% + 组织三角 70% + FinnGen 双显著 100% 是硬资产；但 KCNJ11/PCSK9/APOC3 全是已知靶点，一致率目前只算在 MR 显著子集上、**无召回维度**。直接投只有 IF 3-4。

破局关键判断：**项目的结构性弱点（coloc 只跑 819 对 = 只有精度没有召回）正是最大机会**。全部硬数据都在盘上（eQTLGen 全量 4.3G、GTEx 6 组织、UKB-PPP 8 蛋白已解压、FinnGen/LD 参考就绪）。**单一篇文章 = 一个完整故事**：把 ① 全转录组 coloc 扫描（819→49,866，补召回维度）、② 蛋白层扩到 76 优先编码基因（介质层分解）、③ 结局扩到 8-9（泛化性）作为**同一篇文章的三个结果章节**，围绕一个科学问题讲到底。产出 = 全转录组共定位图谱（新资源）+ cis-MR 二维操作特性（新方法学读数）+ 介质层分解表（生物主体），三者在"cis-MR 作为药物靶点筛选工具到底可不可靠、信号落在哪个分子层"这一个故事线下统一。

## 2. 方案 A（首选）：全转录组共定位图谱 + cis-MR 二维操作特性（精度 × 召回）

**一句话**：把 coloc 从 MR 显著子集（819 对）扩到全量 49,866 对，得到全转录组共定位图谱，并首次算出 MR 的**召回率**——与已有 12.9% 精度合起来，构成"cis-MR 筛查操作特性"方法学框架。

**核心分析**：① 16,622 基因 × 3 结局全量 coloc.abf（p12=1e-5，cis ±1Mb，与现设定一致），输入 = eQTLGen 全量 + 三个结局全量 GWAS（需下载，区域本地提取）；② 两个互补统计量——精度 P(coloc≥0.8|MR p<0.05)=106/819=12.9% [Wilson CI]，召回 P(MR p<0.05|coloc≥0.8)=106/N_coloc_total（粗估 N≈400-800 → 召回约 15-25%，**MR 漏掉约 3/4 共定位位点**）；③ 假阳性控制：把 E1 置换标定框架扩到全扫描命中集（按 eQTL 功效分层的 ~300-500 对 × 100 次置换 → 设全图谱阈值 FWER/FDR 5%，已知位点校准）；④ 产出"coloc-only 位点"（coloc 强但 MR p≥0.05）清单，四维证据分筛选。

**为什么可能破局**：审稿人问"为什么没有新基因"会反转为"**coloc 找到、标准单工具 cis-MR 漏掉的基因，正好说明药物靶点 MR 实践的低召回**"。任何 coloc-only 且经多指标复核的基因都是**新分析产出的新候选**。

**数据需求**：新下 ~0.5-1GB（T2D 重下 + CAD + FBG 全量，OpenGWAS/GWAS Catalog，走代理）。

**预期产出**：全转录组 coloc 图谱表（~5 万行）+ 二维操作特性读数（12.9%×~20%）+ coloc-only 新候选清单。

**诚实边界**：①"coloc 比单点 MR 更敏感，我们知道"→ 卖点是**首次把精度与召回放进同一张 2×2 表 + 置换标定阈值**；②"coloc-only 无 MR 支持凭什么算靶点"→ 表述为"优先化候选"，配 HEIDI/Steiger/FinnGen/组织四维证据分；③"eQTLGen 全血 vs T2D β 细胞病"→ 如实写 Limitation，接方案 D。

**可行性**：全量 coloc ~5 万对 × 0.1-0.5s/对 + 数据准备，10 核下 6-12h 墙钟；置换标定 ~500 对 × 100 ≈ 2-4h。**需 arbitrate claim（CPU>5 核）**。风险：T2D 重下遇代理限速（量小）；命中集过大（>1500）置换成本翻倍 → 功效分层抽样控制。

**目标期刊**：**HMG 5.5 保底**；coloc-only 候选四维验证存活 3-5 个 + 组织/胰岛补上 → 冲 Diabetologia 8。

## 3. 方案 B：76 优先编码基因蛋白层扩展 → 介质层分解表（UKB-PPP 主源）

**一句话**：把蛋白层从 11 个手选蛋白扩到 **76 个 strong-coloc 编码基因**，跑对称 pQTL-MR + coloc，输出 76 基因 × 介质层分解表，直接补全项目主线。

**核心分析**：① 查 UKB-PPP Olink 面板覆盖（~20-40 个有 cis-pQTL），有则下无则标"蛋白层不可测"；② pQTL-MR（nsnp≤3→FE 首读）+ coloc.abf，**关键改进：UKB-PPP 用 UKB EUR 人群 + 全频率，规避 deCODE EAF 缺口和冰岛/1000G LD 错配**（coloc-SuSiE 校准失败正根）；③ 介质层分解：双共定位→双介导、单转录→转录介导、单蛋白→蛋白介导；④ 与药物注释合并（74/76 未成药）。

**数据需求**：UKB-PPP 对应蛋白 per-chromosome 文件（S3 开放数据 syn51365303，走代理，~20-40 蛋白 ≈ 12-25GB）；Synapse PAT 已注册。**先覆盖核查再下**。

**诚实边界**：Olink 覆盖可能只 20-40（胞内/膜蛋白缺）；"无蛋白证据≠转录介导"（描述性 + "蛋白层不可测"列）；双共定位基因可能 0-2 → 降级为描述性图谱贡献。

**可行性**：下载 12-25GB 约 2-6h（后台）；MR 可忽略；coloc 只跑显著对 ~1h。风险：S3 限速（须代理）、覆盖核查发现缺失。

**目标期刊**：**Atherosclerosis 5.0 / HMG 5.5**。

## 4. 方案 C：结局扩展 → 一致率泛化为 8-9 结局

**核心分析**：新增 LDL-C/HDL-C/TG（Richardson 2020，M12 已用）+ 缺血性卒中/心衰/高血压/CKD；每结局全量 MR 扫描（分钟级）→ MR 显著集 coloc；主输出**一致率跨结局森林图** + 置换标定，检验 12.9% 是否泛化。

**数据需求**：6 个新结局全量 GWAS（~1-2GB）。

**诚实边界**：本身不产生新发现，是稳健性/泛化性贡献——**必须与 A 打包才有 IF≥6**；单独顶多 Genetic Epidemiology 4.9。

## 5. 方案 D / E

**D 胰岛 eQTL T2D 图谱（组织匹配）**：下 InsPIRE 全区域 cis-eQTL（GEO ~200-500MB），全胰岛基因 × T2D 组织匹配 MR+coloc，找"胰岛显著而全血盲"基因（SLC5A1 模式系统化）。发现潜力最大但**失败率最高**（n≈420 功效弱 + 10/11 方向反转红旗）。目标 Diabetologia 8；失败降级为 A 的敏感性小节。

## 7. 论文完整故事线（讲给审稿人听的一根主线）

### 7.1 科学问题（Introduction 起点）

一个 cis 变异可以同时改变两个分子层——全血细胞转录本（eQTL）与循环血浆蛋白（pQTL）。主流药物靶点 MR 通常只用单条通道（pQTL 或 eQTL），导致两个未回答的问题：

1. **可靠性问题**：单工具 cis-MR（药物靶点 MR 的事实标准）筛出的信号，有多少是真的、漏掉了多少真的？
2. **介质层问题**：当一个共享的 cis 变异对结局有信号时，因果信号到底经转录层还是蛋白层传导？

**生物学/现实意义（本故事存在的理由，非灌水）**：介质层 = 药物靶点"打哪里"——转录层因果 → 干预转录本（ASO/小核酸）；蛋白层因果 → 干预蛋白（单抗/小分子）；双介导 → 双管齐下。介质层分解表直接服务靶点选择，是真实临床决策信息；全转录组共定位图谱是社区可复用的证据底座（推动发展）；精度/召回量化促进 MR 筛药靶实践进步。

### 7.2 假设与可证伪预期（预注册 H1/H2 + 新增）

- H1：分泌型 vs 细胞内蛋白在 pQTL-MR 显著性率与方向一致性上存在差异（H1 现因 n≈0 无法算，Result 2 扩到 76 基因后第一次有统计量）。
- H2：已知药理位点介质层优先级 LOOCV AUR>0.5（阴性则仅描述性报告）。
- **新增（探索性，预注册追加）**：MR 显著集获得共定位支持的比例（精度）显著 <50%，且共定位支持的位点中 MR 召回显著 <50%——若此成立，单工具 cis-MR 作为筛选工具的两维低效得到系统证据。

### 7.3 方法（对称、锁定、可复现）

- 双通道完全对称工具变量标准（cis ±1Mb、p<5e-6、EUR LD clump）+ 同一 MR 主方法 + 同一共定位闸门（coloc.abf PP.H4≥0.8）。
- **新**：coloc 从 MR 显著子集扩展到全转录组 49,866 对；置换标定从 E1 扩展到全扫描命中集；MR 召回 = P(MR p<0.05 | coloc≥0.8)。
- **新**：介质层分解用 UKB-PPP（UKB EUR 人群，规避 deCODE EAF/LD 错配）。
- 纪律：MR 单工具 Wald ≡ SMR 数学恒等（非三方法互证）；全网格如实报告；哈希锁定预注册。

### 7.4 结果（四个章节，一个读数链）

- R1：全转录组 coloc 图谱 + **二维操作特性**（精度 12.9% × 召回 ~20%，Wilson CI + 置换标定）→ "cis-MR 低精度低召回"的核心方法学读数。
- R2：76 基因介质层分解表 → 双介导 / 转录介导 / 蛋白介导 / 双盲，回答"信号落哪个分子层"。
- R3：跨 8-9 结局一致率森林图 → 12.9% 泛化，非结局集偶然。
- R4：四维证据分（HEIDI/Steiger/FinnGen/组织）筛选 coloc 支持位点 → 图谱资源 + 优先化候选表（coloc-only 位点 = 标准 MR 漏掉的、值得优先跟进）。

### 7.5 结论与诚实边界（Discussion）

- **方法学贡献**：首次给单工具 cis-MR 贴上"操作特性曲线"——精度 ~1/7、召回 ~1/5，两维度置换校准过。这是对药物靶点 MR 领域的直接服务。
- **图谱资源**：全转录组共定位图谱 + 介质层分解表，公开供后续优先化。
- **诚实**：无新因果"发现"；所有强命中为已知位点或伪探针（KCNJ11/PCSK9/APOC3 是校准案例）；coloc-only 候选只标"优先化，需独立验证"；全血盲、蛋白层覆盖、LD 面板 haploid 化全部写进 Limitation。

### 8.2 最小可行性验证（2026-08-15，四项实证，见 `results/feasibility_20260815.md`）
