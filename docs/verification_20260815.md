## 结论（先给判定）

**按"四章节 + 介质层生物学 + 冲 8-9 分"形态不值得做**——统计无效 + 生物学过度声明 + 无新发现 + 四拼盘。

**换成本质上真实能撑住的形态值得做**：

> **系统性量化单工具 cis-MR 筛查的操作特性（精度 & 召回）+ 全转录组 coloc 图谱资源**
> 章节 A（方法学，核心）+ C（跨结局泛化），B/D 降级，目标 HMG 5.5–6。

唯一真正可交付的贡献 = **全转录组 coloc 图谱资源**（社区资源，同行没有）。
"精度/召回量化"是真实但有限的贡献，且必须先把召回统计改对。

## §1 召回统计量有方法学缺陷（最关键）

原方案：MR 显著（819 个, p<0.05）∩ coloc≥0.8 仅 20% → 声称"MR 只召回 20% 的共定位"。

评审指出这是**循环论证 / 无关检验**：

- **共享输入**：MR p 与 coloc PP.H4 吃同一套数据（同区域、同 eQTL 效应、同 GWAS 效应）。把两个相关统计量对齐≠操作特性。
- **coloc≥0.8 集被强 eQTL 富集**：eQTL 强 → 单工具 MR 就显著 → "只有 20%" 与自身矛盾。剩余 80% 只有三种解释，方案未分解：
  1. **coloc-only = 弱 eQTL + 强 GWAS**：这是功效陈述（平凡真理），不是机制发现；
  2. **工具选择不匹配**（方法学 bug 或多信号），这是唯一真正有意思的机制；
  3. **coloc 伪阳**：弱 eQTL + 弱 GWAS 在 p12 拉高下 inflate PP.H4。
- **必须做的事**：按 eQTL F × GWAS 峰 p 做 2×2 分层；把 coloc-only 拆成"GWAS 峰 p<5e-8（真共定位，MR 功率问题）vs p≥5e-8（coloc 伪阳候选）"。**精度报曲线而非单点**；**置换零假设对全扫描重新推导**（见 §3）。

## §2 精度 12.9% 不低，是文献常态；但多重检验未做

- 819 个 MR 显著是 p<0.05 名义阈值、~5,000 检验 → ~250 个期望假阳性。"操作特性"承诺的是曲线，只给单点。
- 精度要按"对已知位点命中率"来语境化（GWAS Catalog 已知基因座命中率是转录组级 eQTL-MR coloc 的常态基线），不是孤立报 12.9%。

## §3 E1 置换校准不能外推到全扫描

- 1.45% FP 是在 **106 个 MR 显著区域**上置换校准的；全扫描绝大多数区域无 MR 信号 → 零假设行为不同。全扫描的置换/零假设必须重新推导。

## §4 "coloc-only = 新候选"是红线风险

- 大部分 coloc-only 会落在**已知 GWAS 基因座**。必须逐位点做 GWAS Catalog / Open Targets 注释，报告已知位点占比；不能把 coloc-only 直接当"新候选"。

## §5 "四维证据分"不是 4 个独立维度

- HEIDI/Steiger 共享输入；FinnGen 是队列复现；GTEx 半独立；**InsPIRE 实际是负证据（10/11 反向）**。

## §6 介质层分解（方案 B）不成立

- **76 基因口径错误**：实际 56 编码 + 20 非编码。其中血浆 Olink 只测 ~20–40 个，有强 cis-pQTL 的更少；双共定位基因预计 0–2 个 → **无统计功效**。
  > **[2026-08-16 修正注]** M21 已推翻本句的编码计数：正确为 **76 编码 + 30 非编码**（ukbpp_coverage 76 行全匹配，README §8 已改）。本句"56+20"为过时口径，保留仅作历史记录。
- **"双共定位 = 双介导"是逻辑谬误**：mRNA→蛋白 flux 意味着 eQTL coloc 是关联回响，不是独立介导证据。
- **"介质层 = 打哪里"（ASO vs 抗体）无方法学依据**。
- "转录-only"类别被面板可得性混淆。

## §7 单篇 = 四拼盘，不构成一个故事

- A+C 回答方法学；B 回答生物学；D 回答资源。唯一可焊接的框架："**cis-MR 可靠性（精度 & 召回）随分子层和组织系统变化**"。但 B 的功率瓶颈（0–2 双共定位）是物理限制。
- **期刊判定**：HMG 有条件可达（非保证）；Diabetologia / eBioMedicine 8-9 **按方案自己的诚实标准不可达**（E2 = ≥1 个带正交验证的真正新发现，目前没有）。Result 2 和 Result 4 目前形态是负资产。

## §8 最便宜的决定性检验

- 不再用 400 对：**直接对 5,000–10,000 对分层抽样子集跑全量 coloc**（几小时），拿到紧 q 估计 + 2×2 表；
- coloc-only 命中按 GWAS 峰 p<5e-8 vs eQTL F 分层；
- 零成本先做：106 强位点的 eQTL 功效解析 + 文献基准（GWAS Catalog 已知基因座命中率）。

2. **砍过度声明**：删"双介导 / 打哪里 / coloc-only=新候选"三处；B 改"分子层共定位一致性表"放补充；InsPIRE 反向数据进 Limitation。

## §10b M22 零成本检验结果（2026-08-15 已跑，`results/archive/m22_efqt_power_20260815.csv`）

对 106 strong 位点做 eQTL 功效解析 + GWAS Catalog 文献基准（评审 §8 第三项），结果**部分反转评审的隐含假设**：

1. **eQTL 功效**：106 strong 的 lead cis-eQTL 强度（|Z| 中位 16.4）与全量 16,987 个 lead eQTL（中位 16.3）**无差异**（Mann-Whitney p=0.45），与 MR 显著但非 strong 的 713 位点也无差异（p=0.95）。→ **在 MR 显著集内，PP.H4≥0.8 的判定不按 eQTL 强度走**；eQTLGen lead 本身全极强（全量 |Z| 中位 ≈ p<1e-50），eQTL 侧不再是分辨 strong/non-strong 的维度。这**支持 M20 以 GWAS 峰 p 分层为主判据**（§1 点 3 里"弱 eQTL + 强 GWAS"叙事在 MR 显著集内不适用）。
2. **文献基准**：106 strong 命中 GWAS Catalog T2D/CAD（rsID 直命 26 + gene±100kb 32）= **55%**（t2d 53%、cad 57%、fbg 50%）；**45%（48/106）超出已报道注释范围 = 新候选比例上限**（诚实：未命中≠新发现，受 catalog 覆盖与窗口限制）。
   > **[2026-08-16 修正注]** 55%/45% 为 **build 错位版**数字（坐标窗口错配系统性低估），已被 M22b 修复后 **81% 命中 / 19% 上限**取代（rsid 26 + gene_100kb 59 + gene_anno 1 = 86/106；feasibility §7.8）。另外全量扫描新增的 **23 个 sig 内新 strong 已用 M25/M25b 单独注释**（15 已知位点新效应基因 / 8 无 catalog 弱候选），不再依赖 106 集的 19% 上限。2026-08-16 起论文口径以 M22b + M25/M25b 为准。

## §11 修订后的诚实叙事（README/方案 §0 已对齐）

- **核心故事**：跨 3 结局全转录组单工具 cis-MR 筛查，操作特性（精度/召回）随 GWAS 信号强度与 eQTL 强度如何变化；全转录组 coloc 图谱作为社区资源。
- **不做**：不声称"新候选基因"，不声称"介质层→打哪里"，不声称双介导；结果 2/4 降级为资源/复现佐证。
- **期刊目标**：HMG 5.5–6（不冲 8-9）。
