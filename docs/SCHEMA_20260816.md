# Schema / Column Dictionary — cis-MR × coloc atlas (2026-08-16, FDR-core)

This document defines every column of the atlas result tables released with the
manuscript. All coordinates are hg19 for eQTLGen/1000 Genomes; the T2D/CAD/FG GWAS
were matched to eQTLGen **by rsID only** (build-independent), so no coordinate
field is reported for the GWAS side. See `docs/PREREGISTRATION.md` for the frozen
protocol and `docs/FACTS_20260816.md` for the definitive numbers.

## Conventions

| Term | Definition |
|---|---|
| Pair | one `gene × outcome` cis-MR test (instrument = cis-eQTL within ±1 Mb, p<5e-6, EUR LD-clumped r²<0.01@1000 kb, single-instrument Wald). |
| `ok` | passed QC: valid effect sizes, non-missing p/PP.H4, no flagged failures. 31,371 of 31,373 pairs. |
| MR-significant (raw) | `ok` and `mr_p < 0.05` (4,248 pairs). Reported only as the nominal funnel. |
| **FDR-core** | `ok` and **per-outcome** Benjamini–Hochberg `padj < 0.05` (982 pairs: t2d 394 / cad 576 / fbg 12). Pre-registered primary threshold. |
| Strong coloc | `pp4 (coloc.abf) ≥ 0.8`. |
| Known | 106 strong pairs previously reported (stage-2 grid, `results/grid/transcript_coloc_hits.csv`). |
| Candidate | strong ∩ FDR-core − known = 15 pairs. |
| Gray-zone strong | strong coloc with `mr_p ≥ 0.05` (MR-null): 2 pairs (AP3S2×T2D, ZNF19×CAD). |

Missing values are empty (blank) cells; `.` denotes a missing/not-applicable
replication field.

## 1. `results/fdr_core_20260816.csv` — 982 FDR-core pairs

| Column | Meaning |
|---|---|
| `gene` | Ensembl gene ID (ENSG…). |
| `symbol` | Gene symbol. |
| `outcome` | Trait: `t2d` / `cad` / `fbg`. |
| `mr_b` | cis-MR effect (per unit eQTL effect; single-instrument Wald). |
| `mr_p` | Raw MR p-value (two-sided Wald). |
| `padj` | Per-outcome BH-FDR q-value. |
| `gwas_min_p` | Minimum GWAS p across the locus window. |
| `eqtl_F_max` | Maximum eQTL F-statistic among cis variants. |
| `nsnp` | Number of cis variants in the window. |
| `pp4` | coloc.abf posterior probability of shared causal variant (H4). |
| `strong` | Boolean: `pp4 ≥ 0.8`. |

## 2. `results/strong_all_subset_20260816.csv` — 123 strong pairs (121 FDR-core + 2 gray-zone)

Columns as §1 plus:

| Column | Meaning |
|---|---|
| `set` | `fdr_core_strong` or `gray_zone`. |
| `status` | `strong (FDR-core)` or `strong (MR-null)`. |

## 3. `results/candidate15_replication_20260816.csv` — 15 candidate effector genes

Columns as §1 (FDR-core subset) plus:

| Column | Meaning |
|---|---|
| `ok` | QC pass (always True here). |
| `padj` | Per-outcome BH-FDR q (all < 0.05). |
| `is_new` | Always True (candidate = not in 106 known). |
| `tier` | `known_locus_100kb_novel_gene` / `known_locus_250kb_novel_gene` / `no_catalog_t2dcad`. |
| `catalog_gene_t2dcad` | Whether the gene itself has a T2D/CAD GWAS Catalog record. |
| `nearest_cat_kb` | Distance (kb) to the nearest catalog T2D/CAD locus gene. |
| `top_snp` | Lead variant (empty). |
| `direction` | GTEx v8 cross-tissue direction: `consistent` / `conflicting` / `no_gtex_gwas_variant`. |
| `gtex_p` | GWAS p at the GTEx lead variant (when testable). |
| `variant_replicated` | FinnGen R11 variant-level direction (`yes`/`no`). |
| `mr_replicated` | FinnGen R11 gene-level (MR) direction (`yes`/`no`). |
| `finn_p` | FinnGen R11 p at the aligned variant (empty if not alignable). |

## 4. `results/coloc_full_{t2d,cad,fbg}_20260815.csv` — full atlas (31,373 pairs)

| Column | Meaning |
|---|---|
| `gene`, `symbol`, `outcome`, `mr_b`, `mr_p`, `gwas_min_p`, `eqtl_F_max`, `nsnp`, `pp4` | As §1. |
| `ok` | QC pass. |
| `note` | Flag/annotation for failed or flagged rows (e.g. empty result, build-window warning). |

## 5. `results/m36b_funnel_20260816.csv` — operating-characteristics funnel

| Column | Meaning |
|---|---|
| `threshold` | MR p threshold (nominal); NaN for the FDR-core and stage-2-grid points. |
| `n` | Number of pairs passing the threshold. |
| `strong` | Number with PP.H4 ≥ 0.8. |
| `yield` | `strong / n`. |
| `kind` | `nominal` (raw funnel), `fdr_core`, or `stage2_grid`. |

## 7. `results/m34_coloc_susie_20260816.csv` — coloc.susie sensitivity (6 loci)

| Column | Meaning |
|---|---|
| `gene`, `symbol`, `outcome`, `mr_p` | As §1 (the 5 candidate loci + LAMC1). |
| `abf_pp4` | coloc.abf PP.H4. |
| `susie_pp4` | coloc.susie PP.H4 under external 1000G EUR LD (exploratory; see note). |
| `n_snps` | Variants in the locus window. |

> Non-convergence of SuSiE under external LD is reported in
> `docs/INTEGRITY_AUDIT_20260816.md`（附录 B）; the SuSiE results are treated as

> credible sets), independent of the non-converged posterior.
